# Contrato piloto
kernel.schema.json es el formato de intercambio mínimo del piloto y de los fixtures. evidence_specs.availability jamás significa evidencia validada. La implementación debe añadir esquemas versionados para source references, specs completos, receipts, candidatos y releases conforme a docs/03_CONTRATOS.md. No ampliar el esquema silenciosamente ni aceptar campos desconocidos.
El validador adjunto comprueba un subconjunto de reglas administrativas y de AST para probar los fixtures. No sustituye el checker Rust, Lean ni el análisis de alcance científico. Su rechazo de ciclos es conservador cuando hay argumentos alternativos: la implementación completa debe construir DAG por derivación, no rechazar una afirmación con prueba acíclica válida solo porque exista otra derivación circular.
